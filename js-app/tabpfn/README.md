# @sap-ai-sdk/tabpfn

> [!CAUTION]
> **Experimental preview — not published to npm.**
> This package ships as a local workspace package inside this repository only.
> It is not available via `npm install` and has no stability guarantees.
> The API, types, and generated client may change without notice.

SAP Cloud SDK for AI client for the [TabPFN](https://github.com/automl/TabPFN) foundation model.
Sends labeled training rows and prediction rows in a single request; the model returns predictions without a separate training step.

## Usage (within this workspace only)

The package is referenced as `@sap-ai-sdk/tabpfn: "workspace:*"` in `js-app/agent/package.json`.
Import from the workspace path — do not attempt to install from a registry.
