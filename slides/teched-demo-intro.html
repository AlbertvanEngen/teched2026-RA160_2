The App Storyline

A financial planning app powered by an AI agent. The agent helps financial analysts query budget vs. actual data, run trend forecasts, and validate predictions — all via natural language.

🆕

Three Core Capabilities

OData Access — pull financial planning & journal entry data from S/4HANA APIs via SAP Cloud SDK.

Agentic Behavior — tool-calling loop with Spring AI and OrchestrationClient.

RPT Predictions — SAP Tabular Model 1.5 for budget forecasting.
